# KOTOMASTER

Кошачий мессенджер для браузера: комнаты по коду, чат в реальном времени, видеозвонки и демонстрация экрана.

## Что уже работает

- создание приватной комнаты с шестизначным кодом;
- вход в существующую комнату по коду;
- список участников и статус нахождения в звонке;
- сообщения в реальном времени;
- видеозвонки и аудио через WebRTC;
- включение и выключение камеры и микрофона;
- демонстрация экрана с возможностью остановить её;
- адаптивный интерфейс для компьютера и телефона;
- ограничение до 6 участников в комнате.

## Запуск на компьютере

Нужен Node.js 20 или новее. Рекомендуется актуальная LTS-версия Node.js.

1. Распакуй архив.
2. Открой терминал в папке `kotomaster`.
3. Выполни:

   ```bash
   npm install
   npm start
   ```

4. Открой в браузере `http://localhost:3000`.
5. Чтобы проверить звонок, открой эту страницу во втором браузере или на другом устройстве и войди по коду комнаты.

Камера и микрофон на `localhost` доступны в современных браузерах. Для доступа с другого устройства через интернет нужен HTTPS.

## Публикация через GitHub и Render

1. Создай новый репозиторий GitHub и загрузи в него **содержимое** папки `kotomaster`.
2. В Render выбери **New → Web Service** и подключи этот репозиторий.
3. Укажи:
   - Runtime: `Node`;
   - Build Command: `npm install`;
   - Start Command: `npm start`.
4. Создай Web Service и дождись окончания первого Deploy.
5. Открой выданный Render URL. Он работает по HTTPS, поэтому браузер сможет запросить разрешение на камеру, микрофон и показ экрана.

Render передаёт приложению порт через переменную `PORT`; сервер уже использует её автоматически.

## Важные ограничения первой версии

- Комнаты и последние 80 сообщений хранятся в памяти сервера. После перезапуска сервера история и комнаты очищаются. Это не постоянное хранилище.
- Видеосвязь использует P2P-схему WebRTC. Для небольших комнат она подходит, но нагрузка растёт с каждым участником; поэтому установлен лимит 6 человек.
- Для соединения в некоторых сетях может понадобиться TURN-сервер. Без него STUN-соединение иногда не проходит через строгие NAT или корпоративные сети. Для TURN можно добавить в Render Environment Variables `TURN_URL`, `TURN_USERNAME` и `TURN_CREDENTIAL`. Сервер передаст эти параметры браузерам через `/api/config`.
- Указанные TURN-учётные данные видны браузерам участников. Для публичного продукта следует использовать краткоживущие TURN credentials, а не постоянный пароль.
- Код комнаты — это пропуск. Передавай его только тем, кого приглашаешь. В первой версии нет аккаунтов, списка контактов, восстановления доступа или постоянной базы данных.
- Браузер всегда спрашивает разрешение на доступ к камере/микрофону и отдельно открывает системный выбор экрана для демонстрации. Скрытого включения камеры или записи экрана нет.

## Технологии

- Node.js + Express — веб-сервер;
- Socket.IO — комнаты, события участников и чат;
- WebRTC — аудио, видео и передача экрана напрямую между браузерами;
- HTML, CSS и JavaScript — интерфейс.
